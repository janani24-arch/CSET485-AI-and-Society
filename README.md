# CSET485 – AI and Society: Assignment 1

## Project overview

This project studies the Adult Census Income dataset and examines how predictive models can produce different classifications, how model results change across demographic subgroups, and how fairness measures can conflict.

The notebook is designed to reproduce the preprocessing, model comparisons, stress-tests, tables, and charts used in the assignment report.

## Dataset

- **Dataset:** UCI Adult Census Income dataset
- **Source:** https://archive.ics.uci.edu/ml/machine-learning-databases/adult/
- **Target:** Whether annual income is greater than $50K
- **Train/test split:** 70% training and 30% testing
- **Random seed:** 548 (based on the last three digits specified for this assignment)

The notebook may download the dataset when run. If the dataset download or source changes, follow the dataset-loading instructions in the notebook.

## What's included

- Data preprocessing: missing values, categorical encoding, feature scaling, and outlier handling
- Part 1: Linear Regression vs. Logistic Regression comparison
- Part 2:
  - Subgroup analysis
  - Omitted-variable test
  - High-confidence incorrect predictions
  - Fairness metrics across decision thresholds
- Tables, charts, and computed results used to support the written report

## Requirements

Python 3.10 or later is recommended. Install the libraries listed in `requirements.txt`.

## How to run

1. Clone or download this repository.
2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Open `Assignment_1_ai_and_society.ipynb` in Jupyter Notebook or Google Colab.
4. Run all cells from top to bottom.
5. Check that the outputs, tables, and charts are generated successfully.

For a reproducibility check, restart the notebook kernel/runtime before running all cells.

## Reproducibility notes

- The notebook should be run from beginning to end to regenerate its results.
- Use the random seed and split defined in the notebook consistently.
- Results in the PDF report should match the results generated by the notebook.
- The notebook's trained model objects exist in the active Python session unless the code explicitly saves them as separate files.
